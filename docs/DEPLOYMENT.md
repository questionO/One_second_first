# 静态部署与回滚

## 本地发布预览

~~~powershell
npm ci
npm run test
npm run build
npm run preview -- --port 5174
~~~

打开 http://127.0.0.1:5174。生产构建位于 dist，可部署到支持静态文件的 Nginx、对象存储或其他静态托管。游戏不需要 API 地址、环境密钥、数据库或服务端运行时。

构建使用相对资源路径，可放在独立站点根目录，也可放在静态子目录；子目录访问地址须以斜杠结尾。不要通过 file:// 直接打开 index.html，浏览器模块需要 HTTP 服务。

## 推荐发布操作

1. 保留当前版本的完整 dist 备份，使用规则版本与构建日期命名发布目录。
2. 将新构建上传到新的版本目录，先验证 index.html、脚本、CSS、图标返回正常。
3. 验证开始、教学、手机横屏操作、借时、还债、结算和刷新。
4. 切换静态站点入口或目录链接至新版本。
5. 保留上一版本完整资源，直到确认没有白屏或资源加载失败。

本次实施不会修改任何现有 CRM/Nginx 服务或执行公网发布。

## 缓存

- index.html：Cache-Control: no-cache。
- assets/ 下带内容哈希的文件：Cache-Control: public, max-age=31536000, immutable。
- favicon.svg：短缓存或更新校验。
- 开启 gzip 或 Brotli；关闭目录列表，正确返回 JavaScript、CSS 和 SVG MIME。
- 本地存档和域名绑定；更换域名不会自动迁移纪录。
- 不缓存不存在的资源为 HTML，否则可能导致模块 MIME 报错。

## 回滚

切回上一版本完整目录，清除入口 HTML 的 CDN 缓存并验证旧资源仍然可访问。无需数据库回滚。存档格式升级时应保留旧版本读取或迁移策略；当前只有版本 1。

## 发布后观察

首版不包含远程埋点或账号数据采集。通过静态服务器 404/5xx、浏览器控制台及用户提供的种子／规则版本定位问题。收到成绩异常时先排除本地存档修改；本地分数不是可信在线成绩。
