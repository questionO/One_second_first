# 静态部署与回滚

## 本地发布预览

~~~powershell
npm ci
npm run test
npm run build
npm run preview -- --port 5174
~~~

打开 http://127.0.0.1:5174。生产构建位于 dist，可部署到支持静态文件的 Nginx、对象存储或其他静态托管。游戏不需要 API 地址、环境密钥、数据库或服务端运行时。

构建使用相对资源路径，可放在独立站点根目录，也可放在静态子目录；子目录访问地址须以斜杠结尾。不要通过 file:// 直接打开 index.html，浏览器模块需要 HTTP 服务。

## 局域网手机试玩

3.0.0 使用当前电脑的 Wi-Fi 地址启动生产预览，自动化验证与未完成的真机验收分别记录在 VERIFICATION.md：

~~~powershell
npm run preview -- --host 192.168.1.224 --port 5174 --strictPort
~~~

手机连接同一局域网，在浏览器打开 http://192.168.1.224:5174/?v=3.0.0，横屏试玩。如果浏览器锁定竖屏，点击「直接横屏试玩」，再把手机横着拿；页面会自动调整画面和摇杆方向。电脑需要保持开机、网络连接和预览进程运行；此命令读取 dist，代码修改后须重新构建。电脑 IP 改变时须更新监听地址和防火墙规则。

Windows 放行规则名为 OneSecondFirst-LAN-5174：仅允许 WLAN 接口、D:\nodejs\node.exe、本机 192.168.1.224 的 TCP 5174，来源限于 192.168.1.0/24。原来的 5173 开发服务仍只监听本机。

结束试玩后，可在管理员 PowerShell 撤销此规则：

~~~powershell
Remove-NetFirewallRule -Name 'OneSecondFirst-LAN-5174'
~~~

已从电脑通过该局域网地址验证 HTTP 200、资源无加载失败、手机触屏仿真开始和借时成功、生产诊断接口已移除。手机到电脑的实际 Wi-Fi 链路仍需真机打开确认。

## 推荐发布操作

1. 保留当前版本的完整 dist 备份，使用规则版本与构建日期命名发布目录。
2. 将新构建上传到新的版本目录，先验证 index.html、脚本、CSS、图标返回正常。
3. 验证开始、教学、手机横屏操作、借时、还债、结算和刷新。
4. 切换静态站点入口或目录链接至新版本。
5. 保留上一版本完整资源，直到确认没有白屏或资源加载失败。

本次实施不会修改任何现有 CRM/Nginx 服务或执行公网发布。

## 缓存

- index.html：Cache-Control: no-cache。
- assets/ 下带内容哈希的文件：Cache-Control: public, max-age=31536000, immutable。
- favicon.svg：短缓存或更新校验。
- 开启 gzip 或 Brotli；关闭目录列表，正确返回 JavaScript、CSS 和 SVG MIME。
- 本地存档和域名绑定；更换域名不会自动迁移纪录。
- 不缓存不存在的资源为 HTML，否则可能导致模块 MIME 报错。

## 回滚

切回上一版本完整目录，清除入口 HTML 的 CDN 缓存并验证旧资源仍然可访问。无需数据库回滚。3.0 使用独立 v3 键，优先导入 v2、其次 v1 设置，旧键保留；回滚读取相应旧版成绩。

## 发布后观察

首版不包含远程埋点或账号数据采集。通过静态服务器 404/5xx、浏览器控制台及用户提供的种子／规则版本定位问题。收到成绩异常时先排除本地存档修改；本地分数不是可信在线成绩。
