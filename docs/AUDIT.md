# 1.0.1 代码与边界审计

日期：2026-10-21。审计对象为此目录中的项目自有代码；不是对 node_modules 内第三方实现的逐行审计，也不是所有设备、输入序列与并发调度的形式化证明。

## 范围与方法

逐文件检查全部 13 个 src 文件，以及 HTML、SVG 图标、构建与测试配置、许可证复制脚本、存档格式、规则和部署说明。对确定的问题先增加失败用例，再修复并执行相关及完整回归。

| 区域 | 检查重点 |
|---|---|
| game/balance、types、simulation | 借贷上限、精确期限、操作优先级、死亡优先于拾取与兑现、每局重置 |
| game/clock、collision | 30/60/120 帧固定步、长间隔、暂停、扫掠碰撞、激光圆角及预警结束边界 |
| game/patterns | 九种编排、随机种子、难度边界、实体数量、金币及危险的换波寿命 |
| main | 菜单、教学、失败、完成、设置、暂停、恢复倒计时、结算之间的转换 |
| input | 键盘默认行为、按钮焦点、连按、多点触控、pointercancel、失焦和监听器清理 |
| storage | 损坏数据、读取异常、写入失败与恢复、未知格式、最近二十局、多个页面依次写入 |
| audio | 静音、API 缺失、上下文中断、节点异常、暂停停止及卸载关闭 |
| scene、digits、style | 绘制与规则隔离、分辨率设置、状态反馈、数字显示、最小横屏布局 |
| 工程与发布 | 严格类型检查、相对资源路径、生产诊断接口移除、许可证随包输出 |

## 已处理的问题

| 问题 | 处理与验证 |
|---|---|
| 激光在第 108 个预警步提前造成伤害 | 完整预警后才开始 36 步伤害；覆盖冻结预警和最后激活步 |
| 还债的第二个子步仍处理上一波危险、金币 | 每个机关子步结束时立即换波；旧弹幕与过期金币不会多存在一步 |
| 一个方向为 NaN/Infinity 时另一轴超速或停止 | 先清理非有限值，再归一化方向 |
| 重复进入设置、恢复倒计时进入设置后丢失本局 | 设置入口防重入；恢复过程先暂停，并保留返回位置 |
| 教学金币全部按普通方式拾取后卡在第二步 | 自动重置第二步并提示先借时再拾取 |
| 教学失败或完成后从设置返回到了错误页面 | 独立记录失败和完成状态，返回时恢复相应操作 |
| 追平旧成绩也显示刷新纪录 | 以存档实际是否更新最佳成绩为准 |
| 结算按钮最初禁用导致键盘焦点遗留在背景 | 先聚焦结算面板，解锁后聚焦再来一局 |
| 聚焦还债按钮后空格被全局借时快捷键截获 | 聚焦按钮时保留其原生空格激活行为 |
| 覆盖层后的教学按钮仍可获得键盘焦点 | 暂停和遮挡时使用 inert；竖屏禁止启动隐藏游戏 |
| 存档读取失败时用默认值覆盖已有内容 | 读取失败时仅使用内存；未知更高格式版本保留原内容 |
| 写入恢复后仍显示无法保存 | 成功写入时恢复持久化标志 |
| 已打开页面保存旧快照覆盖其他页纪录和设置 | 写入前读取并合并最新纪录、教学状态和未修改设置；失败局次暂存后补写；相同种子的两局不去重 |
| 合并其他页面的画质设置后画布尺寸未同步 | 保存状态刷新时同步应用显示设置，尺寸不变时不重复调整 |
| 音频中断后不恢复、节点异常可能打断游戏事件处理 | 支持非运行状态恢复；声音故障不外抛；停止时断开节点，卸载时关闭上下文 |
| 冻结外框 CSS 选择器未匹配实际元素 | 修正选择器，并检查实际计算颜色 |

主要回归文件：`tests/audit.test.ts`、`tests/audio.test.ts`、`tests/browser/audit.spec.ts`。原有规则、存档、触屏和生产测试继续保留。

|---|---|

| TypeScript 严格检查 | 通过 |

| Chrome 浏览器流程 | 22 项通过，含新增 14 项边界回归 |

本次耐久在真实键盘触发下反复借时并自动还债，样本包含成功兑现。画布和场景始终各一个，采样实体最多 21 个。JS 堆采样范围 20.54～51.71 MiB，首末分别为 26.49／23.08 MiB；监听器范围 92～156，首末为 99／98。存在回收波动，本次采样未显示持续增长。帧耗时离散采样为 2.0～79.4 ms，不是全量分位数，也不能证明手机达到 60 FPS。原始数据见 [soak.json](verification/soak.json)。

执行命令：`npm run verify`；设置 BROWSER_PATH 为本机 Edge 后执行 `npm run test:browser -- --output=test-results-edge`；`npm run test:soak`。

## 尚未证明的边界

- Android/iPhone 真机的温升、系统手势、音频中断恢复、浏览器安全区域及实际帧率；触屏仿真不能替代真机。
- localStorage 的读取与写入不是跨页面事务。已覆盖多个页面依次保存和失败补写；完全同时写入仍不提供强一致性保证，本地成绩也不是可信在线成绩。
- 十分钟采样不是严格无泄漏证明，也不是长期留存或真人乐趣验收。
- 本次没有公网部署、CDN 缓存验收、真人试玩或第三方依赖源码的全面安全审计。

通过的用例证明覆盖场景内的行为；不能据此承诺以后绝不会出现问题。后续修改应保留这些回归，并在玩法行为变化时更新规则版本。
