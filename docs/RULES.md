# 规则与数值 3.0.0

主玩法为无尽战斗生存；无跨局属性成长。普通玩家 8–12 分钟一局是调参目标，尚未通过真人验收。

## 时间与稳定结算

固定步 60 Hz。移动、武器冷却、连射、装填、无敌、护盾与借还时间按个人时钟；敌人、弹体、危险区、刷怪、掉落寿命按世界时钟。普通 / 冻结 / 还债每个人步推进 1 / 0 / 2 世界步。

借时最长 60 步、至少 15 步后可提前还债；欠债最多 180 步，首次借时建立 480 个人步到期时间，连续借时不延期。自然结束回普通状态，主动解冻立即还债。活着时个人步数减世界步数等于欠债。

冻结仍会受到接触与已有危险区伤害。每次伤害扣一格并提供 60 个人步无敌。每步先处理敌人接触、敌弹和危险，再处理奖励、拾取、升级与清债；任何子步致命伤都终止该步收益。护盾先于生命消耗；一次性致命保护保留一格并无敌 120 步。

远程冻结布弹位置和寿命停止，发射方向固定；近战即时命中。冻结斩痕储存已结算直接伤害的 25% / 50% / 75%，解冻一次性兑现，不重复计算暴击与护甲。死亡后不兑现。

## 六系双武器

只允许当前武器攻击，Q 或屏幕按钮切换，切换冷却 18 个人步。两个槽位的冷却与装填继续，切换不重置冷却，取消未发出的连珠且不扣后续弹药。

| 系列 | 基础伤害 / 间隔步 / 范围 | 三阶 | 六阶分支 |
|---|---|---|---|
| 枪械 | 1 / 24 / 400 | 冲锋枪 | 机枪 / 穿甲步枪 |
| 弓箭 | 2 / 42 / 500 | 复合弓 | 连珠弓 / 重弩 |
| 刀剑 | 2.5 / 30 / 65 | 长刀 | 双刃 / 环刃 |
| 长枪 | 3 / 40 / 110 | 长枪 | 穿阵枪 / 回旋枪 |
| 战锤 | 5 / 65 / 70 | 重锤 | 震地锤 / 破城锤 |
| 雷电 | 1.5 / 36 / 330 | 电弧器 | 连锁电杖 / 雷矛 |

武器最高六阶，每阶比一阶增加 10% 基础伤害；三阶攻击间隔乘 0.85，冲锋枪额外乘 0.6。机枪间隔再乘 0.7、弹匣翻倍；穿甲步枪伤害三倍、间隔乘 2.5、射程乘 1.3、穿透四目标。连珠弓每次三组，间隔六个人步；重弩伤害乘 2.5、间隔乘 1.5、射程乘 1.2、额外穿透三目标。穿阵枪长度乘 1.5、伤害乘 1.3；破城锤伤害乘 1.8、间隔乘 1.25。其他分支改变攻击形状、余震或连锁目标。

同一系不能占两槽。初始可选枪、弓、剑。满槽拾取暂停选择替换或分解；该系阶级与专属卡本局保留。同系远程补该系弹药，同系近战给通用补给。

枪械初始总量 60（12 发弹匣 + 48 备弹），装填 72 个人步；备弹上限 180。弓箭 36、上限 108；电池 40、上限 120。每份通用补给给每个携带远程武器补初始量的 25%，向上取整。近战不耗弹。所有远程耗尽后使用范围 48、伤害 1.5、间隔 36 步的应急挥击，不丢失装备。

自动瞄准范围内最近活跃目标，同距按实体 ID。无目标、装填中或容量不足不扣弹与玩法随机数。多重箭整组扣一支；连珠每组单独扣。友方弹速 480，寿命最多 120 世界步，达到射程提前结束。

## 43 张成长卡

六张武器研修、六张通用攻击、四张生存、六张时间与切换、十二张武器专属、两张即时补给、七张策略卡。完整名称、限制和描述集中在 `src/game/upgrades.ts`，武器基础及分支倍率在 `src/game/arsenal.ts`。

- 通用每级：伤害 +12%、攻击间隔 -8%、范围 +15%、暴击率 +5 个百分点、击退 +20%、拾取 +25%，最高三级。基础暴击 5%，倍率 1.75，同一组攻击共享一次暴击结果。
- 最大生命最高两级，每级 +1，不治疗；护盾恢复 20 / 16 / 12 个人秒；每 60 / 45 / 30 击杀恢复一格；致命保护本局一次。
- 冷凝爆破半径 32 + 8×级，伤害原弹×0.5×级，排除直接目标；回响八向，伤害实际偿还秒数×0.5×级；还债步伐每级 +8%。
- 清债装填使用现有备弹填充弹匣的 25% / 50% / 100%；切换强击两个人秒内首攻 +20% / 40% / 60%，至少三秒触发间隔。
- 专属包括扩容、跳弹、多重箭、贯穿、刀锋范围、格挡、背向突刺、破甲、余波、减速、额外连锁与过载。二次伤害不递归触发效果。
- 医疗卡恢复两格；补给卡一份通用补给。满生命 / 弹药无收益时排除。升级不再自动回血。

经验阈值 `8 + 4×(当前等级-1)`。基础三选一，策略最多七选三。候选必须唯一、合法；最多两张策略，至少一半有实际战斗或补给收益。研修和专属卡只针对携带武器。若所有战斗与补给均无收益，保留经验，等再次具备合法收益时再生成。

| 策略卡 | 下轮效果 |
|---|---|
| 双选契约 / 连选契约（稀有） | 多选一 / 两张 |
| 拓展视野 / 博览契约（稀有） | 多两个 / 四个候选 |
| 超频成长（稀有） | 所选战斗卡双份提升 |
| 命运重掷 | 一次重掷 |
| 定向研修 | 指定当前武器，下轮保证一张该系成长卡 |

策略占本次选择，不立即加战力，不作用当前轮。稀有卡五级开放，权重为普通策略的四分之一。候选 / 多选超过上限的额度顺延；超频不乘成四倍，多次次数逐轮使用。普通强化受等级上限，研修双升跨六阶只进化一次；复活、策略不翻倍。选全策略也消耗本轮超频。

卡牌实例、已选项、剩余次数、重掷、本轮强化和下一轮奖励独立保存。设置、旋转、后台不刷新。重掷保留已选效果、次数和强化，优先避开旧候选。定向目标离场则改用当前合法武器，没有合法武器就保留额度。进化 / 替换不消耗策略奖励。所有决定完成后倒数一秒恢复原时间状态。

## 敌人、首领与补给

基础三怪保持原值：追猎生命4 / 速度80 / 成本1，冲锋6 / 55 / 2，炮手4 / 45 / 3。冲锋速度420，最多27世界步，每目标互伤3点、每次一次，撞墙结束。普通敌弹不互伤。

| 新敌人 | 开放世界分钟 | 生命 / 速度 / 成本 | 技能 |
|---|---:|---|---|
| 盾卫 | 2 | 12 / 38 / 3 | 正面减伤60%，慢转向，后期盾击 |
| 医师 | 4 | 6 / 42 / 3 | 治疗最多3名非医师、非首领同伴15%最大生命，直接受击打断 |
| 分裂体 | 5 | 9 / 60 / 2 | 死后两只生命2幼体，不再分裂 |
| 布雷者 | 7 | 8 / 40 / 3 | 玩家旧位置延迟危险区 |

攻击预警至少90世界步，不因后期缩短。六分钟后炮手扇射、冲锋怪追加一次独立预警冲锋。三分钟起每分钟生命增加12%，速度增加2.5%，速度增幅封顶35%。精英保持三倍生命、1.15倍速度、四倍成本。

每180世界秒排入一位首领：破阵者（冲锋 / 扇形重击）、围猎炮台（扇射 / 错峰轰击）、裂隙织者（缺口弹环 / 延迟爆区）循环。基础生命100 / 120 / 140，每循环增加25%。登场提示三秒，暂停普通补怪；存活首领最多一位，待出现首领排队。首领可被冻结。首领存活时普通补怪预算减半，已存在敌人不清除。

预算前一分钟4，一至三分钟8，之后每三分钟 +4，最高32。敌人最多16（含出生预警与首领），敌弹96、友方弹128、斩痕64、危险区12、全部掉落8、旧爆雷1。触顶延后生成，首领 / 精英保证奖励排队。分裂幼体受敌人上限限制。

每18世界秒武器掉落；每15秒尝试弹药。远程全部耗尽五世界秒内安排一份近身可达补给，场上已有弹药则不重复；实体满额时按统一上限延后。普通击杀4%医疗包（满血不拾取），精英保证弹药及武器，首领保证医疗和弹药。首领300分、12经验；精英100分、8经验。欠债期间得分暂存，清债双倍，经验当步存活即到账。

## 兼容与验证边界

应用 / 规则 3.0.0，存档 `one-second-first.save.v3`。只迁移 v2 设置，缺少有效 v2 时尝试 v1；旧键不改、新成绩独立、新教学五步。不保存跨局构筑。存储不可用时内存运行，多标签合并设置与成绩。

模拟测试和桌面手机布局模拟不能证明真机30 FPS、输入延迟或趣味性。至少五人试玩和手机15分钟尚需实际执行，记录见 PLAYTEST.md。
