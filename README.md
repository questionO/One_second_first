# 先欠一秒

横屏 2D 无尽战斗生存：六系双武器、分支进化、43 张成长卡、最多七选三与下轮效果翻倍，冻结布弹并挑战阶段首领。当前版本 3.0.0。

## 本地运行

使用 Node.js 22.18+ 或 24.12+；本次验证环境为 Node.js 24.21.0。

~~~powershell
cd E:\One_second_first
npm ci
npm run dev
~~~

打开 http://127.0.0.1:5173 。第一次进入会进行五步互动教学。

同一局域网手机试玩时使用：

~~~powershell
npm run dev -- --host 0.0.0.0
~~~

在手机浏览器打开电脑局域网 IP 的 5173 端口，横屏游玩。浏览器不自动旋转时，点击「直接横屏试玩」，再把手机横着拿；页面会自行旋转画面和触控方向，不依赖全屏或系统方向锁定接口。仅在需要时开放本地防火墙；这不是公网部署。

## 怎么玩

- WASD／方向键移动；手机左侧摇杆移动。
- 靠近怪物自动攻击；枪械、弓箭、刀剑、长枪、战锤、雷电六系武器可占主副两个槽。Q／切换按钮更换当前武器，远程弹药耗尽时应急近战。
- 空格／「借 1 秒」：冻结敌人与双方弹体，你继续移动、射击布弹。已有危险仍会扣血。
- E／「开始还债」：冻结满 0.25 秒后即可提前解冻齐射；敌人和双方弹体两倍速，直至还清实际欠债。
- 每轮最多欠三秒，第一次借时后的八秒内必须还清。再次借时不会延期，来不及偿还时不能继续借。
- 初始三格生命，受伤后一秒保护。后期加入盾卫、医师、分裂体与布雷者，每三世界分钟排入一位阶段首领。
- 欠债时的击杀分数暂存，还清后翻倍；经验立即获得，升级从三选一成长到七选三，可投资下轮候选、多选、重掷和效果翻倍。升级不自动回血；依靠恢复卡、医疗掉落与首领奖励。所有成长仅限本局。
- 三分钟后可能出现小范围爆雷：冻结触碰预警核心可拆弹，暂存 30 分，清债后 60 分。已爆炸区域不能拆除。
- Esc 暂停。失焦、切后台、竖屏及超过 250ms 的运行中断也会暂停；返回后手动继续。
- 结算页可用同一个种子重试，也可以开始新局面。

首次升级至 3.0 优先迁移 v2、其次 v1 设置，旧存档保留原样，新成绩与教学独立。完整数值见 [规则](docs/RULES.md)，真人难度和手机性能待按 [试玩表](docs/PLAYTEST.md) 验收。

## 验证命令

~~~powershell
npm run test
npm run build
npm run test:browser
npm run test:release
npm run test:soak
~~~

浏览器测试默认使用 Windows 安装的 Chrome。覆盖其他安装位置：

~~~powershell
$env:BROWSER_PATH = 'C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe'
npm run test:browser
~~~

也可以将 BROWSER_PATH 设为其他本地 Chromium 的可执行文件。耐久测试实际运行十分钟，并在 docs/verification/soak.json 输出原始采样。普通浏览器测试不会等待十分钟。

## 工程

- TypeScript 严格模式，Phaser 4.2.0，Vite 8，Vitest，Playwright。
- src/game：60Hz 固定步模拟、个人／世界双时钟、扫掠碰撞、种子刷怪、三类敌人、武器与六项本局升级；旧机关保留开发诊断入口。
- src/scene.ts：仅绘制与视觉反馈，不计算债务或分数。
- src/input.ts：键盘和独立 pointerId 多点触控。
- src/main.ts：菜单、教学、结算、状态栏与运行生命周期。
- src/storage.ts：版本化本地存档，损坏或不可用时继续运行。
- src/audio.ts：原生 Web Audio 原创合成音效，无远程音频依赖。

游戏与 CRM/OA 项目独立，无账号、后台服务和数据库。本地成绩可被用户修改，不用于在线排行榜。
